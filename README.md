## Controls

| Key | Action(orbit cam/free cam) |
|---|---|
| **WASD** | Move camera target / Move in space |
| **Right Mouse Button** | Rotate camera |
| **Mouse Wheel** | Zoom in/out / Change speed |
| **Space / Left Shift** | Move Up / Down |
| **Tab** | Switch Camera Mode (Orbit / Free) |
| **P** | Pause / Resume simulation |
| **R** | Pause / Resume render |
| **T** | Hide / Show dark matter |
