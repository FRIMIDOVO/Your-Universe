# 🌌 Your Universe

# Build
Для сборки в `.exe` необходимо иметь установленный компилятор *MinGV* (подробнее на сайте [MSYS2](https://www.msys2.org/)). Для корректной работы надо установить *SFML* (см. credits) и изменить файл `build.bat`,
а именно: заменить пути к папкам `...\SFML-3.1.0\include` и `...\SFML-3.1.0\lib` на свои.

# Configs
Рекомендую поместить ярлыки конфигов, которые находятся в папке `bin\`, в папку `configs` для более быстрого и удобного доступа к ним. В конфигах есть возможность настраивать
как сами *физические параметры симуляции*, такие как:
- **G** ~10 отвечает за силу гравитации
- **gravity_degree** `-1, 0, 0.5, 2...` степень действия гравитации; в формуле Ньютона - 2
- **softening** `0 - 1 - 10` сглаживание, дабы не было резких скачков скоростей
- **K_elasticity** `0 - 1` коэффициент эластичности столкновений частиц
- **F_stickiness** `~10` сила прилипания(пока фигня какая-то, не так работает, как хочу, поэтому рекомендую ставить 0)
- **K_friction** `0 - 1` коэффициент трения между частицами
- **contact_distance** `0.01 - 0.1` множитель дистанции на которой начинает действовать трение

а также *параметры визуализации и записи*:
- **record** `0|1` выкл/вкл запись кадров(влияет на производительность)
- **with, height** `~800` размеры окна в пикселях
- **width_texture, height_texture** `~800` размер текстуры, именно она и сохраняется при записи
- **show_velocity_vec** `0|1` выкл/вкл показ векторов скорости
- **vector_scale** `~0.5` размер вектора в условных единицах
- **max_speed_color** `~15` скорость до которой растягивается градиент вектора, показывающий быстроту
- **arrow_size** `~0.2` размер стрелки вектора в условных единицах
- **arrow_angle** `~0.4` угол стрелки вектора в радианах
- **show_hex_cells** `0|1` выкл/вкл показ активных ячеек сетки.

# Encode MP4 / GIF
Записанные кадры симуляции будут находиться в папке `bin\frames\` в формате `.png`. Для создания видео или гиф анимации из них, необходимо запустить `encode_video.bat` или `encode_gif.bat` соответственно.
Файлы с названием `record.*` появятся в папке `bin\`. Для корректной работы этиз бат-файлов нужно иметь устрановленную программу *FFmpeg* (подробнее на сайте [FFmpeg](https://ffmpeg.org/)).
